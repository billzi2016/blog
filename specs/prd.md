# Hugo 博客 PRD

## 目标

搭建一个轻量、可长期维护的个人博客，用 Hugo 生成静态站点，通过 PaperMod 主题提供通用博客能力，并通过 GitHub Actions 部署到 GitHub Pages。

## 核心定位

- 文章按照题目组织，标题是主要入口。
- 日期作为辅助信息，用于记录发布时间和归档排序。
- 支持以后持续写日记、笔记、项目记录和文章。

## 用户场景

- 作者每天或不定期新增文章。
- 读者通过首页查看最新文章。
- 读者通过文章列表按发布时间浏览。
- 读者通过标签查看相关主题。

## 内容模型

每篇文章使用 Markdown 文件，放在 `content/posts/` 下。

Front matter 字段：

- `title`：文章标题，作为主要展示信息。
- `date`：发布时间，用于排序和辅助展示。
- `draft`：是否为草稿。
- `slug`：文章 URL 标识。
- `tags`：标签。
- `categories`：分类。
- `summary`：摘要。

## 页面需求

- 首页：展示站点说明和最新文章。
- 文章列表页：展示全部文章，按日期倒序排列。
- 文章详情页：展示标题、日期、标签和正文。
- 标签页：支持按主题聚合文章。
- 通用博客能力优先使用 PaperMod 主题，不自行维护等价模板。

## 部署需求

- 使用 GitHub Actions 自动构建 Hugo。
- 推送到 `main` 分支后触发部署。
- 构建产物上传到 GitHub Pages。

## 非目标

- 暂不接入评论系统。
- 暂不接入 CMS。
- 暂不自写主题已有的页面模板、SEO、RSS、导航和响应式布局。
